### ALGO-000081: Optimal exponent for fixed-size clique detection
- **Subfield:** Fine-grained and exact exponential complexity
- **Open:** For fixed \(k\) divisible by three, determine whether \(k\)-clique detection can beat the matrix-multiplication-based exponent \(\omega k/3\) by a fixed positive amount.
- **Status:** Matrix multiplication supplies the standard general benchmark. Its optimality is conjectural and should not be confused with NP-hardness when \(k\) is part of the input.
- **Type:** theory
- **Why:** Would sharpen fine-grained complexity of dense subgraph detection.
- **Key works:** Nešetřil and Poljak (1985), *On the Complexity of the Subgraph Problem*; Vassilevska Williams (2018).
- **Related:** Network science—small dense-pattern detection.
